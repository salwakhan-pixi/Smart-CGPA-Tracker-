# Smart CGPA Tracker & Degree Progress Planner

## Project Overview:
**Smart CGPA Tracker & Degree Progress Planner** is a console-based C programming project designed to help university and college students manage and track their academic progress.
The program allows students to record their semester courses, credit hours, and grades. It automatically calculates semester GPA and overall CGPA while also helping students monitor their degree completion and plan their future academic performance.

## Objectives:
The main objectives of this project are to:
* Calculate semester GPA automatically.
* Calculate overall CGPA.
* Store and manage semester records.
* Display semester-wise academic reports.
* Track degree completion based on credit hours.
* Help students determine the GPA required to achieve a target CGPA.
* Save academic records so they can be accessed later.
* Provide a simple and easy-to-use menu-driven interface.

## Features:

### 1. Add Semester Record:
Users can enter:
* Semester number
* Course names
* Credit hours
* Grades
  
### 2. Automatic GPA Calculation:
The program calculates the GPA of each semester using course grades and credit hours.

### 3. Automatic CGPA Calculation:
The program combines the academic records of all semesters to calculate the student's overall CGPA.

### 4. Semester-wise Report:
Users can view their courses, credit hours, grades, GPA, and other academic information in an organized format.

### 5. Edit/Delete Records:
Users can correct incorrect information or remove an existing semester record.

### 6. Degree Progress Tracker:
The program calculates the percentage of the degree completed based on completed credit hours.

### 7. Target CGPA Simulator:
Users can enter a desired CGPA, and the program calculates the average GPA required in their remaining semesters to reach that target.

### 8. Save/Load Data:
Academic records are stored in a file so that data is not lost when the program is closed.

### 9. Menu-Driven Interface:
A simple numbered menu allows users to access different features of the system.
